プライバシーポリシー

1. 取得する情報

Cat Gatekeeper Desktopは、ユーザーの個人情報を取得しません。
本アプリは、動作に必要なタイマー設定だけをユーザーのコンピューター内に保存します。

  • 作業時間の設定
  • 休憩時間の設定
  • 自動くり返しの設定
  • 表示言語などのアプリ設定

2. 保存方法

設定は、ユーザーのコンピューター内に保存されます。
これらの情報が外部サーバーへ送信されることはありません。

3. 収集しない情報

本アプリは、以下の情報を取得・収集・販売・送信しません。

  • 氏名、メールアドレスなどの個人情報
  • 広告IDや端末識別子
  • ブラウザ履歴、閲覧サイト、アプリ使用状況
  • キーボード入力、画面内容、ファイル内容
  • 個人を特定できる情報

4. 外部サービス

本アプリは、広告、解析、トラッキングのための外部サービスを使用しません。

5. 第三者提供

Cat Gatekeeper Desktopがユーザーの情報を第三者に提供することはありません。

6. お問い合わせ

お問い合わせは、zokuzoku.app@gmail.com までお願いします。

7. 改定について

本ポリシーは、必要に応じて変更される場合があります。
