プライバシーポリシー

Cat Gatekeeperでは、ユーザーの個人情報を一切取得しません。

1. 取得する情報

本拡張機能は、以下の情報をブラウザ内にのみ保存します。

  • SNSごとの有効・無効設定
  • 使用時間の上限設定
  • 休憩時間の設定

これらは個人を特定する情報ではありません。

2. 取得方法

取得した情報は、ブラウザのローカルストレージ（chrome.storage.local）にのみ保存されます。
外部サーバーへ送信されることはありません。

3. 外部サービスの利用

本拡張機能は、外部サービスやトラッキングツールを一切使用しません。

4. 個人情報・識別子の取り扱い

本拡張機能は以下の情報を取得・収集しません。

  • 氏名、メールアドレスなどの個人情報
  • 広告IDや端末識別子
  • 閲覧履歴やSNSの利用内容
  • 個人を特定できる情報

5. 第三者提供

取得した情報を第三者に提供することはありません。

6. お問い合わせ

ご不明点・不具合はこちらまでご連絡ください：zokuzoku.app@gmail.com（件名にCat Gatekeeperとご記入ください）

7. 改定について

本ポリシーは必要に応じて変更される場合があります。
