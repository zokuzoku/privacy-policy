Cat Gatekeeper ブラウザ拡張機能・デスクトップアプリ共通

1. 適用範囲

本ポリシーは、ZOKUZOKUが提供するCat Gatekeeperのブラウザ拡張機能と、macOS・Windows向けデスクトップアプリに適用されます。製品によってデータの取扱いが異なるため、以下でそれぞれ分けて説明します。

2. ブラウザ拡張機能

ブラウザ拡張機能は、動作に必要な以下の情報をブラウザのローカルストレージに保存します。

  • 対象サイトの設定
  • 使用時間の上限設定
  • 休憩時間の設定
  • タイマーの状態

これらの情報は外部サーバーへ送信されません。拡張機能は、広告、解析、トラッキングのための外部サービスを使用しません。

3. デスクトップアプリで端末内に保存する情報

デスクトップアプリは、機能を提供するために以下の情報をユーザーのコンピューター内に保存します。

  • 作業時間、休憩時間、自動くり返し、表示言語などのアプリ設定
  • ユーザーが「うちの子」機能で明示的に選択した猫の画像とモーション設定
  • 「みんなの子」と、有料看板猫機能が提供されている場合に購入または有効なサブスクリプションで利用できる素材
  • 購入機能が提供されている場合の、購入済み商品の識別子、サブスクリプションの契約状態・有効期限・自動更新状態、確認日時、ダウンロード状態などの権利情報
  • 更新通知の確認状態

「うちの子」に追加した写真と生成画像は端末内で処理・保存され、外部サーバーへアップロードされません。

4. デスクトップアプリの通信

デスクトップアプリは、次の目的に限ってHTTPS通信を行います。

  • 更新通知と公開されている「みんなの子」の情報・画像を取得するため
  • 有料看板猫機能が提供されている場合に、App StoreまたはMicrosoft Storeでの購入・復元・サブスクリプションの契約状態を確認するため
  • 有料看板猫機能が提供されている場合に、購入または有効なサブスクリプションで利用できる素材をダウンロードするため

有料看板猫機能が提供され、購入またはサブスクリプションの確認が必要な場合には、ストアが発行した取引識別子または購入権利を確認するためのStore IDキーを、ZOKUZOKUの購入確認サービスへ送信します。サービスはAppleまたはMicrosoftへ照会し、対象商品の購入権利またはサブスクリプションが有効か確認します。氏名、メールアドレス、カード番号、請求先情報をZOKUZOKUが受け取ることはありません。

通信時には、IPアドレス、アクセス日時、リクエスト先、応答状態などの技術情報が、配信・不正利用防止・障害調査のためにホスティング事業者で処理される場合があります。

5. 利用する外部サービス

  • Apple App Store・Microsoft Store: 有料看板猫機能が提供されている場合の決済、購入、復元、サブスクリプション管理、権利確認
  • Cloudflare Workers・R2: 有料看板猫機能が提供されている場合の購入・サブスクリプション確認、不正リクエストの制限、素材配信
  • GitHub Pages・Cloudflare R2: 更新通知と公開コンテンツの配信

各事業者は、それぞれのプライバシーポリシーに基づいてデータを処理します。Cat Gatekeeperは、広告配信、行動追跡、ユーザープロファイリングのためにこれらのサービスを利用しません。

6. 保存期間と安全管理

端末内の設定、写真、素材、権利情報は、ユーザーがアプリ内で削除するか、アプリデータを削除するまで保存されます。ストアの購入履歴とサブスクリプション契約はAppleまたはMicrosoftが各社の方針に従って管理します。

有料看板猫機能の提供時も、ZOKUZOKUの購入確認サービスはユーザーアカウントを作成せず、取引識別子を恒久的な顧客データベースへ保存しません。CloudflareのWorkerログにはリクエスト・レスポンスの技術的なメタデータが最大7日間保存される場合があります。アプリの購入・サブスクリプション確認リクエスト本文や取引識別子を独自ログへ記録する処理は実装していません。

購入・サブスクリプション確認と素材配信には暗号化されたHTTPS通信を使用し、素材へのアクセス許可は短時間で失効するトークンで制御します。

7. 取得・利用しない情報

Cat Gatekeeperは、以下の情報を取得・販売・広告利用しません。

  • 氏名、メールアドレスなど、ユーザーが問い合わせ時に自ら提供する場合を除く直接的な連絡先情報
  • カード番号、銀行口座、請求先情報
  • 広告ID、連絡先、位置情報
  • 閲覧履歴、閲覧ページ、SNS投稿、他のアプリの使用状況
  • キーボード入力、画面内容、「うちの子」機能で明示的に選択した画像以外のファイル内容

ユーザー情報を販売せず、第三者広告やクロスサービス・トラッキングに使用しません。

8. ユーザーによる管理

拡張機能の設定はブラウザから、デスクトップアプリの「うちの子」はアプリ内から削除できます。その他の端末内データはアプリデータを削除することで消去できます。ストアの購入履歴、決済情報、サブスクリプションの確認・解約についてはAppleまたはMicrosoftの管理機能をご利用ください。
